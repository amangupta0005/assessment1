## Architectural Decisions Log
1. **Decision Cutoff Timestamp**:
   - For delivery date $D$, day-ahead decision is taken on $D - 1$.
   - Default cutoff: 09:00 UK local time (GMT = UTC in January).
   - Only forecasts with `publishTime <= (D-1) 09:00` are eligible.
2. **Granularity Harmonization**:
   - Primary metric view uses hourly-averaged actuals to align with 1-hour WINDFOR forecasts.
   - Exact half-hourly / `:00` view preserved as an option.
3. **Data Caching**:
   - Local cached Parquet / JSON dataset generated by `scripts/fetch_data.py` to guarantee zero latency and offline reproducibility.
4. **Sign Convention**:
   - Error = Actual - Forecast ($A - F$). Positive = Surplus, Negative = Deficit.
   - Shortfall = $\max(0, F - A)$ (MW deficit). P90 Shortfall = Recommended thermal hedge buffer.
